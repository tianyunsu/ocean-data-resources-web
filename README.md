# 海洋数据资源清单 · 可检索网页版

**打开网页：<https://tianyunsu.github.io/ocean-data-resources-web/>**

323 项海洋数据资源，可按类别、质控等级、可爬取方式、国家/地区筛选，
每条带说明、评分明细与**可直接点击的批量下载入口**（OPeNDAP / THREDDS / ERDDAP / FTP / 直链）。

## 网页能做什么

- **搜索**：名称 / 机构 / 国家 / 说明 / 下载入口全文检索，支持空格分词（如 `Argo 法国`）
- **筛选**：9 大类别 × 质控等级（A/B/C/D）× 可爬取类型（✅API / ✅直链 / ⚠️需凭证 / 🔶半自动 / ❌不可）× 国家地区 × 验证状态
- **排序**：点表头排序，默认按总分降序
- **展开详情**：点资源名称，看说明、评分明细（可获取/开放/元数据/质控/持续/覆盖/互操作）、全部下载入口
- **复制链接**：展开后点「复制全部下载入口」，直接粘到下载脚本里用
- **导出**：按当前筛选条件导出 CSV
- **快捷键**：按 `/` 聚焦搜索框；手机端自动切换为卡片视图

## 质控等级怎么看

| 等级 | 含义 |
|---|---|
| **A** | 有公开可追溯质控流程与质控标志，且有文献/官方报告给出定量精度 |
| **B** | 有质控流程与标志，但缺独立公开的定量比测结果 |
| **C** | 仅基础/自动质控，或质控责任在数据提交者 |
| **D** | 无公开质控流程（聚合仓储、目录门户） |
| **N/A** | 失效条目或机构/计划门户，不适用 |

## 关于本仓库

- 本仓库的 `index.html` **由源仓库自动生成，请勿直接编辑**——源仓库每次同步会整覆盖。
- 清单内容（Markdown 源）与调研依据维护在源仓库，本仓库只放生成后的网页。
- 同步链路：源仓库 push → GitHub Actions 运行 `tools/build_site.py` → 推送本仓库 → Pages 自动发布。
