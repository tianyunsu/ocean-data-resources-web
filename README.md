# 海洋数据资源清单 · 可检索网页版

**打开网页：<https://tianyunsu.github.io/ocean-data-resources-web/>**

323 项海洋数据资源，可按类别、质控等级、可爬取方式、国家/地区筛选，
每条带说明、评分明细与**可直接点击的批量下载入口**（OPeNDAP / THREDDS / ERDDAP / FTP / 直链）。

## 网页能做什么

- **搜索**：名称 / 机构 / 国家 / 说明 / 下载入口全文检索，支持空格分词（如 `Argo 法国`）
- **筛选**：9 大类别 × 质控等级（A/B/C/D）× 可爬取类型（✅API / ✅直链 / ⚠️需凭证 / 🔶半自动 / ❌不可）× 国家地区 × 验证状态
- **排序**：点表头排序，默认按总分降序
- **展开详情**：点资源名称，看说明、评分明细（可获取/开放/元数据/质控/持续/覆盖/互操作）、全部下载入口
- **复制链接**：展开后点「复制全部下载入口」，直接粘到下载脚本里用
- **导出**：按当前筛选条件导出 CSV
- **快捷键**：按 `/` 聚焦搜索框；手机端自动切换为卡片视图
- **图例**：页面顶部「图例与使用说明」折叠区可查质控等级与可爬取标记的含义

## 质控等级怎么看

| 等级 | 含义 |
|---|---|
| **A** | 有公开可追溯质控流程与质控标志，且有文献/官方报告给出定量精度 |
| **B** | 有质控流程与标志，但缺独立公开的定量比测结果 |
| **C** | 仅基础/自动质控，或质控责任在数据提交者 |
| **D** | 无公开质控流程（聚合仓储、目录门户） |
| **N/A** | 失效条目或机构/计划门户，不适用 |

## 可爬取标记怎么看

| 标记 | 含义 |
|---|---|
| ✅ API | 有 OPeNDAP / THREDDS / ERDDAP / REST / FTP / S3 接口，可脚本化批量下载，**免凭证** |
| ✅ 直链 | 可直接 HTTP/FTP 拉取文件，**免凭证** |
| ⚠️ 需凭证 | 需先申请账号（Earthdata / CMEMS / CDS / AVISO 等），配置一次后可长期自动 |
| 🔶 半自动 | 仅网页交互下载或需人工申请审批，无法完全脚本化 |
| ❌ 不可 | 已失效、需商业授权或明确不提供批量下载 |
| ℹ️ N/A | 机构/计划门户等非数据资源条目，不适用 |

> 「网址」列是数据集主页（用于了解产品），**「下载入口」列才是真正取数的 endpoint**。

## 关于本仓库

- 本仓库的 `index.html` **由源仓库自动生成，请勿直接编辑**——源仓库每次同步会整覆盖。
- 清单内容（Markdown 源）与调研依据维护在源仓库，本仓库只放生成后的网页。
- 同步链路：源仓库 push → GitHub Actions 运行 `tools/build_site.py` → 推送本仓库 → Pages 自动发布。

## 源仓库还有这些内容（暂为私有）

本网页只呈现 323 条清单与下载入口。源仓库另维护：

- **470 条**权威依据链接（官方文档、用户手册、ATBD、验证报告与文献 DOI）；

  叶绿素-a / 海冰密集度 / 降水 / 水深 / 海洋重力），给出同一海区同基准下的 RMSE、bias
  与「什么情况不能用」；

- 链接可达性的三轮实测记录与判定口径（2026-09-27：240 / 317 可达，17 条待处理）。

## 许可与提醒

- 数据资源本身的许可以其发布方为准，批量下载前请自行核对条款（尤其商业用途与再分发）。
- **403 不等于失效**：NASA、GBIF 等站点的 403 多为反爬策略，浏览器通常可正常访问。
